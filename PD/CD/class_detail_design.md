# クラス詳細設計ドキュメント

## クラス名
DatabaseConnection

## アプリケーション名
API Backend

## 概要
`DatabaseConnection` クラスは、PostgreSQL データベースとの接続を管理し、データの取得、挿入、更新、削除を行うための中心的な役割を果たします。このクラスは、データベース接続の確立、クエリの実行、エラー処理を担当します。システム全体のデータ永続化層として機能し、他のサービスクラスから呼び出されます。

## 使用ライブラリ
- psycopg2: PostgreSQL データベース接続用
- logging: ログ記録用
- os: 環境変数の取得用

## フィールド

| フィールド名         | 型              | 説明                                                                 |
|----------------------|-----------------|----------------------------------------------------------------------|
| `connection`         | psycopg2.Connection | データベース接続オブジェクト。データベースとの通信を管理します。         |
| `cursor`             | psycopg2.Cursor | クエリを実行するためのカーソルオブジェクト。                           |
| `db_host`            | str             | データベースホスト名。環境変数から取得されます。                       |
| `db_port`            | int             | データベースポート番号。環境変数から取得されます。                     |
| `db_name`            | str             | データベース名。環境変数から取得されます。                             |
| `db_user`            | str             | データベースユーザー名。環境変数から取得されます。                     |
| `db_password`        | str             | データベースパスワード。環境変数から取得されます。                     |
| `logger`             | logging.Logger  | ログ記録用のロガーオブジェクト。                                      |

## メソッド

| メソッド名           | 戻り値の型       | 説明                                                                 |
|----------------------|-----------------|----------------------------------------------------------------------|
| `__init__`           | None           | クラスの初期化を行い、データベース接続を確立します。                   |
| `connect`            | None           | データベース接続を確立します。                                       |
| `execute_query`      | list[dict]     | SQL クエリを実行し、結果を返します。                                  |
| `execute_update`     | int            | 更新系クエリを実行し、影響を受けた行数を返します。                     |
| `close_connection`   | None           | データベース接続を閉じます。                                         |
| `handle_error`       | None           | エラーを処理し、ログに記録します。                                   |

## フィールド詳細

### `connection`
- **型:** psycopg2.Connection
- **説明:** データベースとの接続を管理するオブジェクト。`connect` メソッドで初期化されます。

### `cursor`
- **型:** psycopg2.Cursor
- **説明:** SQL クエリを実行するためのカーソルオブジェクト。`connect` メソッドで初期化されます。

### `db_host`
- **型:** str
- **説明:** データベースホスト名。環境変数 `DB_HOST` から取得されます。

### `db_port`
- **型:** int
- **説明:** データベースポート番号。環境変数 `DB_PORT` から取得されます。

### `db_name`
- **型:** str
- **説明:** データベース名。環境変数 `DB_NAME` から取得されます。

### `db_user`
- **型:** str
- **説明:** データベースユーザー名。環境変数 `DB_USER` から取得されます。

### `db_password`
- **型:** str
- **説明:** データベースパスワード。環境変数 `DB_PASSWORD` から取得されます。

### `logger`
- **型:** logging.Logger
- **説明:** ログ記録用のロガーオブジェクト。エラーや操作履歴を記録します。

## メソッド詳細

### `__init__`
- **メソッド定義タイプ:** `def`
- **目的:** クラスの初期化を行い、データベース接続情報を設定します。
- **パラメータ:** なし
- **戻り値:** なし
- **処理詳細:**
  1. 環境変数からデータベース接続情報を取得します。
  2. ロガーオブジェクトを初期化します。
  3. `connect` メソッドを呼び出してデータベース接続を確立します。

### `connect`
- **メソッド定義タイプ:** `def`
- **目的:** データベース接続を確立します。
- **パラメータ:** なし
- **戻り値:** なし
- **処理詳細:**
  1. psycopg2 を使用してデータベース接続を確立します。
  2. 接続オブジェクトとカーソルオブジェクトを初期化します。
  3. 接続成功時にログを記録します。
  4. 接続エラーが発生した場合は `handle_error` メソッドを呼び出します。

### `execute_query`
- **メソッド定義タイプ:** `def`
- **目的:** SELECT クエリを実行し、結果を返します。
- **パラメータ:**
  - `query` (str): 実行する SQL クエリ。
  - `params` (tuple): クエリに渡すパラメータ。
- **戻り値:** list[dict] (クエリ結果のリスト)
- **処理詳細:**
  1. クエリを実行する前に入力を検証します。
  2. psycopg2 のカーソルを使用してクエリを実行します。
  3. 結果をフェッチし、リスト形式で返します。
  4. エラーが発生した場合は `handle_error` メソッドを呼び出します。

### `execute_update`
- **メソッド定義タイプ:** `def`
- **目的:** INSERT、UPDATE、DELETE クエリを実行します。
- **パラメータ:**
  - `query` (str): 実行する SQL クエリ。
  - `params` (tuple): クエリに渡すパラメータ。
- **戻り値:** int (影響を受けた行数)
- **処理詳細:**
  1. クエリを実行する前に入力を検証します。
  2. psycopg2 のカーソルを使用してクエリを実行します。
  3. 影響を受けた行数を取得して返します。
  4. エラーが発生した場合は `handle_error` メソッドを呼び出します。

### `close_connection`
- **メソッド定義タイプ:** `def`
- **目的:** データベース接続を閉じます。
- **パラメータ:** なし
- **戻り値:** なし
- **処理詳細:**
  1. カーソルオブジェクトを閉じます。
  2. 接続オブジェクトを閉じます。
  3. 接続終了時にログを記録します。

### `handle_error`
- **メソッド定義タイプ:** `def`
- **目的:** エラーを処理し、ログに記録します。
- **パラメータ:**
  - `error` (Exception): 発生した例外。
- **戻り値:** なし
- **処理詳細:**
  1. エラー内容をロガーに記録します。
  2. 必要に応じてエラーを再スローします。

## クラス間の関係マッピング
- **依存関係:**
  - `menu_items` テーブル: メニュー情報の取得、更新、削除に使用。
  - `users` テーブル: ユーザー情報の取得、更新、削除に使用。
  - `roles` テーブル: 役割情報の取得、更新、削除に使用。
  - `logs` テーブル: 操作履歴の記録に使用。
- **呼び出し元クラス:**
  - `MenuManagementService`: メニュー管理機能でクエリを実行。
  - `UserManagementService`: ユーザー管理機能でクエリを実行。
  - `RoleManagementService`: 役割管理機能でクエリを実行。
- **呼び出し先クラス:**
  - psycopg2: データベース接続とクエリ実行に使用。
  - logging: エラーや操作履歴の記録に使用。

# クラス詳細設計ドキュメント

## クラス名
Logger

## アプリケーション名
API Backend

## 概要
`Logger` クラスは、システム全体のログ記録を管理するためのユーティリティクラスです。このクラスは、アプリケーション内で発生するイベント、エラー、警告、情報メッセージを記録し、システムの監査やデバッグに役立てることを目的としています。ログは、JSON形式でファイルに保存され、必要に応じて外部のモニタリングシステムに送信されます。

このクラスは、システム内の他のクラスから呼び出され、ログ記録を一元的に管理します。ログレベル（INFO、WARN、ERROR）に応じて、適切な処理を行います。また、ログの保持期間や容量の管理も行います。

## 使用ライブラリ
- `logging`: Python 標準ライブラリ。ログの記録と管理に使用。
- `os`: 環境変数の取得やファイル操作に使用。
- `json`: ログをJSON形式で保存するために使用。

## フィールド

| フィールド名         | 型              | 説明                                                                 |
|----------------------|-----------------|----------------------------------------------------------------------|
| `logger`             | logging.Logger  | ログ記録用のロガーオブジェクト。                                      |
| `log_file_path`      | str             | ログファイルの保存先パス。                                           |
| `log_level`          | str             | ログレベル（INFO、WARN、ERROR）。                                    |
| `max_log_size`       | int             | ログファイルの最大サイズ（バイト単位）。                              |
| `backup_count`       | int             | ログファイルのバックアップ数。                                       |

## メソッド

| メソッド名           | 戻り値の型       | 説明                                                                 |
|----------------------|-----------------|----------------------------------------------------------------------|
| `__init__`           | None           | クラスの初期化を行い、ロガーオブジェクトを設定します。                 |
| `log_info`           | None           | INFOレベルのログを記録します。                                       |
| `log_warn`           | None           | WARNレベルのログを記録します。                                       |
| `log_error`          | None           | ERRORレベルのログを記録します。                                      |
| `rotate_logs`        | None           | ログファイルのローテーションを管理します。                           |

---

### `logger`
- **型:** logging.Logger
- **説明:** ログ記録用のロガーオブジェクト。`__init__` メソッドで初期化され、ログの記録に使用されます。

### `backup_count`
- **型:** int
- **説明:** ログファイルのバックアップ数。環境変数 `BACKUP_COUNT` から取得されます。

### `log_error`

  - `message` (str): 記録するメッセージ。
  - `extra` (dict, optional): 追加のログ情報。
- **戻り値:** なし
- **処理詳細:**
  1. メッセージと追加情報を受け取ります。

### `rotate_logs`
- **メソッド定義タイプ:** `def`
- **目的:** ログファイルのローテーションを管理します。
- **パラメータ:** なし
- **戻り値:** なし
- **処理詳細:**
  1. ログファイルのサイズを確認します。
  2. サイズが `max_log_size` を超えた場合、古いログファイルをバックアップします。
  3. バックアップ数が `backup_count` を超えた場合、最も古いバックアップを削除します。

# クラス詳細設計ドキュメント

## クラス名
ConfigurationManager

## アプリケーション名
API Backend

## 概要
`ConfigurationManager` クラスは、システム全体の設定情報を管理するためのユーティリティクラスです。このクラスは、環境変数や設定ファイルから設定値を読み取り、キャッシュし、必要に応じて他のクラスやサービスに提供します。設定値の取得、検証、キャッシュ管理を行い、システムの一貫性とパフォーマンスを向上させる役割を担います。

このクラスは、システム内の他のクラスから呼び出され、設定情報を一元的に管理します。設定値の取得時にデフォルト値を提供し、不足している場合や無効な値が検出された場合にはエラーをスローします。

## 使用ライブラリ
- `os`: 環境変数の取得に使用。
- `json`: 設定ファイルの読み取りと解析に使用。
- `logging`: ログ記録に使用。
- `functools`: 設定値のキャッシュに使用。

---

## フィールド

| フィールド名         | 型              | 説明                                                                 |
|----------------------|-----------------|----------------------------------------------------------------------|
| `config_cache`       | dict            | 設定値をキャッシュする辞書。                                         |
| `config_file_path`   | str             | 設定ファイルのパス。環境変数から取得される。                         |
| `logger`             | logging.Logger  | ログ記録用のロガーオブジェクト。                                      |

---

## メソッド

| メソッド名           | 戻り値の型       | 説明                                                                 |
|----------------------|-----------------|----------------------------------------------------------------------|
| `__init__`           | None           | クラスの初期化を行い、設定ファイルのパスとロガーを設定します。         |
| `get_config`         | Any            | 指定されたキーの設定値を取得します。                                 |
| `load_config_file`   | dict           | 設定ファイルを読み込み、設定値をキャッシュします。                   |
| `validate_config`    | None           | 設定値の検証を行い、不正な値があれば例外をスローします。             |
| `clear_cache`        | None           | 設定値のキャッシュをクリアします。                                   |

---

## フィールド詳細

### `config_cache`
- **型:** dict
- **説明:** 設定値をキャッシュするための辞書。`get_config` メソッドで使用され、頻繁な設定値の取得を効率化します。

### `config_file_path`
- **型:** str
- **説明:** 設定ファイルのパス。環境変数 `CONFIG_FILE_PATH` から取得されます。設定ファイルが存在しない場合はエラーをスローします。

### `logger`
- **型:** logging.Logger
- **説明:** ログ記録用のロガーオブジェクト。設定値の読み取りやエラー発生時にログを記録します。

---

## メソッド詳細

### `__init__`
- **メソッド定義タイプ:** `def`
- **目的:** クラスの初期化を行い、設定ファイルのパスとロガーを設定します。
- **パラメータ:** なし
- **戻り値:** なし
- **処理詳細:**
  1. 環境変数 `CONFIG_FILE_PATH` から設定ファイルのパスを取得します。
  2. ロガーオブジェクトを初期化します。
  3. 設定ファイルの存在を確認し、存在しない場合はエラーをスローします。
  4. `load_config_file` メソッドを呼び出して設定値をキャッシュします。

---

### `get_config`
- **メソッド定義タイプ:** `def`
- **目的:** 指定されたキーの設定値を取得します。
- **パラメータ:**
  - `key` (str): 取得する設定値のキー。
  - `default` (Any, optional): 設定値が存在しない場合に返すデフォルト値。
- **戻り値:** Any (設定値)
- **処理詳細:**
  1. `config_cache` を確認し、指定されたキーが存在する場合はその値を返します。
  2. キーが存在しない場合は、`default` を返します。
  3. `default` が指定されていない場合は、`KeyError` をスローします。
  4. ログに取得結果を記録します。

---

### `load_config_file`
- **メソッド定義タイプ:** `def`
- **目的:** 設定ファイルを読み込み、設定値をキャッシュします。
- **パラメータ:** なし
- **戻り値:** dict (設定値の辞書)
- **処理詳細:**
  1. 設定ファイルのパスを使用してファイルを開きます。
  2. JSON 形式でファイルを解析し、設定値を辞書として取得します。
  3. 取得した設定値を `config_cache` に保存します。
  4. ログに読み取り結果を記録します。
  5. エラーが発生した場合は `FileNotFoundError` または `json.JSONDecodeError` をスローします。

---

### `validate_config`
- **メソッド定義タイプ:** `def`
- **目的:** 設定値の検証を行い、不正な値があれば例外をスローします。
- **パラメータ:** なし
- **戻り値:** なし
- **処理詳細:**
  1. 必須の設定キーが `config_cache` に存在するかを確認します。
  2. 各設定値の型や範囲を検証します。
  3. 不正な値が検出された場合は `ValueError` をスローします。
  4. 検証結果をログに記録します。

---

### `clear_cache`
- **メソッド定義タイプ:** `def`
- **目的:** 設定値のキャッシュをクリアします。
- **パラメータ:** なし
- **戻り値:** なし
- **処理詳細:**
  1. `config_cache` を空の辞書にリセットします。
  2. ログにキャッシュクリアの結果を記録します。

---

## クラス間の関係マッピング

- **依存関係:**
  - `os`: 環境変数から設定ファイルのパスを取得。
  - `json`: 設定ファイルを解析。
  - `logging`: 設定値の読み取りやエラー発生時にログを記録。

- **呼び出し元クラス:**
  - `DatabaseConnection`: データベース接続情報の取得に使用。
  - `AuthService`: 認証設定の取得に使用。
  - `MenuManagementService`: メニュー管理設定の取得に使用。

- **呼び出し先クラス:**
  - なし（外部ライブラリのみ使用）。

# クラス詳細設計ドキュメント

## クラス名
JWTAuthenticator

## アプリケーション名
Auth Service

## 概要
`JWTAuthenticator` クラスは、JWTトークンの生成、検証、失効を管理するための中心的な役割を果たします。このクラスは、ユーザー認証後にトークンを生成し、APIリクエストでトークンの有効性を検証します。また、トークンの有効期限切れや不正なトークンに対するエラー処理も行います。このクラスは、システム全体のセキュリティを確保するために重要な役割を担っています。

## 使用ライブラリ
- `jwt`: Python標準ライブラリ。JWTトークンの生成と検証に使用。
- `datetime`: トークンの有効期限を管理するために使用。
- `os`: 環境変数の取得に使用。
- `logging`: ログ記録に使用。

---

| `secret_key`         | str             | JWTトークンの署名に使用される秘密鍵。環境変数から取得されます。       |
| `algorithm`          | str             | JWTトークンの署名アルゴリズム。デフォルトは`HS256`。                 |
| `token_ttl`          | int             | トークンの有効期限（秒単位）。環境変数から取得されます。              |
| `logger`             | logging.Logger  | ログ記録用のロガーオブジェクト。                                      |

## フィールド詳細

### `secret_key`
- **型:** str
- **説明:** JWTトークンの署名に使用される秘密鍵。環境変数 `JWT_SECRET_KEY` から取得されます。

### `algorithm`
- **型:** str
- **説明:** JWTトークンの署名アルゴリズム。デフォルト値は `HS256` で、環境変数 `JWT_ALGORITHM` から取得されます。

### `token_ttl`
- **型:** int
- **説明:** トークンの有効期限（秒単位）。環境変数 `JWT_TOKEN_TTL` から取得されます。デフォルト値は86400秒（1日）です。

### `logger`
- **型:** logging.Logger
- **説明:** ログ記録用のロガーオブジェクト。トークン生成、検証、失効時の操作履歴やエラーを記録します。

## メソッド詳細

### `__init__`
- **メソッド定義タイプ:** `def`
- **目的:** クラスの初期化を行い、必要な設定をロードします。
- **パラメータ:** なし
- **戻り値:** なし
- **処理詳細:**
  1. 環境変数 `JWT_SECRET_KEY` から秘密鍵を取得し、`secret_key` フィールドに設定します。
  2. 環境変数 `JWT_ALGORITHM` から署名アルゴリズムを取得し、`algorithm` フィールドに設定します。デフォルト値は `HS256` です。
  3. 環境変数 `JWT_TOKEN_TTL` からトークンの有効期限を取得し、`token_ttl` フィールドに設定します。デフォルト値は86400秒（1日）です。
  4. ロガーオブジェクトを初期化し、`logger` フィールドに設定します。

---

### `generate_token`
- **メソッド定義タイプ:** `def`
- **目的:** ユーザー情報を基にJWTトークンを生成します。
- **パラメータ:**
  - `user_id` (str): ユーザーの一意の識別子。
  - `roles` (list[str]): ユーザーに割り当てられた役割のリスト。
- **戻り値:** str (生成されたJWTトークン)
- **処理詳細:**
  1. 現在の日時を取得し、トークンの有効期限を計算します。
  2. トークンのペイロードを作成します。ペイロードには以下の情報が含まれます：
     - `user_id`: ユーザーの一意の識別子。
     - `roles`: ユーザーに割り当てられた役割のリスト。
     - `exp`: トークンの有効期限。
  3. `jwt.encode` メソッドを使用してトークンを生成します。`secret_key` と `algorithm` を使用して署名します。
  4. 生成されたトークンをログに記録します。
  5. 生成されたトークンを返します。
- **エラー処理:**
  - `jwt.exceptions.PyJWTError` が発生した場合、エラーメッセージをログに記録し、例外を再スローします。

---

### `verify_token`
- **メソッド定義タイプ:** `def`
- **目的:** トークンの有効性を検証し、ペイロードを返します。
- **パラメータ:**
  - `token` (str): 検証対象のJWTトークン。
- **戻り値:** dict (トークンのペイロード)
- **処理詳細:**
  1. `jwt.decode` メソッドを使用してトークンをデコードします。`secret_key` と `algorithm` を使用して署名を検証します。
  2. デコードされたペイロードをログに記録します。
  3. ペイロードを返します。
- **エラー処理:**
  - トークンが無効な場合、`jwt.exceptions.InvalidTokenError` をキャッチし、エラーメッセージをログに記録します。
  - トークンが期限切れの場合、`jwt.exceptions.ExpiredSignatureError` をキャッチし、エラーメッセージをログに記録します。
  - いずれの場合も、HTTPステータスコード401を返します。

---

### `invalidate_token`
- **メソッド定義タイプ:** `def`
- **目的:** トークンを失効させます。
- **パラメータ:**
  - `token` (str): 失効対象のJWTトークン。
- **戻り値:** なし
- **処理詳細:**
  1. トークンを失効リストに追加します（失効リストはキャッシュまたはデータベースで管理されます）。
  2. 失効操作をログに記録します。
- **エラー処理:**
  - トークンが既に失効している場合、警告をログに記録します。

---

### `decode_token`
- **メソッド定義タイプ:** `def`
- **目的:** トークンをデコードし、ペイロードを取得します。
- **パラメータ:**
  - `token` (str): デコード対象のJWTトークン。
- **戻り値:** dict (トークンのペイロード)
- **処理詳細:**
  1. `jwt.decode` メソッドを使用してトークンをデコードします。署名の検証は行いません。
  2. デコードされたペイロードをログに記録します。
  3. ペイロードを返します。
- **エラー処理:**
  - トークンが無効な場合、`jwt.exceptions.InvalidTokenError` をキャッチし、エラーメッセージをログに記録します。

---

## 概要
`PasswordHasher` クラスは、ユーザーのパスワードを安全にハッシュ化および検証するためのユーティリティクラスです。このクラスは、認証プロセスの一環として、ユーザーが入力したパスワードをハッシュ化し、データベースに保存されているハッシュ値と照合する役割を担います。ハッシュ化には、セキュリティ要件で指定された `bcrypt` ライブラリを使用します。

このクラスは、システム全体で再利用可能なユーティリティとして設計されており、認証サービス内の他のクラスから呼び出されます。パスワードのハッシュ化と検証は、ユーザー認証の重要な部分であり、セキュリティを確保するために強力な暗号化アルゴリズムを使用します。

## 使用ライブラリ
- `bcrypt`: パスワードのハッシュ化と検証に使用される暗号化ライブラリ。

| フィールド名         | 型              | 説明                                                                 |

| メソッド名           | 戻り値の型       | 説明                                                                 |

| `hash_password`      | str            | パスワードをハッシュ化し、ハッシュ値を返します。                      |

## フィールド詳細

### `salt_rounds`
- **型:** int
- **説明:** ハッシュ化に使用するソルトのラウンド数。セキュリティ要件に基づき、デフォルト値は12に設定されます。この値は、ハッシュ化の計算コストを調整するために使用されます。

## メソッド詳細

### `__init__`
- **メソッド定義タイプ:** `def`
- **目的:** クラスの初期化を行い、ソルトラウンド数を設定します。
- **パラメータ:** 
  - `salt_rounds` (int, optional): ソルトラウンド数。デフォルト値は12。
- **戻り値:** なし
- **処理詳細:**
  1. `salt_rounds` パラメータが提供されている場合、その値をフィールドに設定します。
  2. 提供されていない場合、デフォルト値の12を使用します。
  3. 初期化が完了したことをログに記録します。

---

### `hash_password`
- **メソッド定義タイプ:** `def`
- **目的:** パスワードをハッシュ化し、ハッシュ値を返します。
- **パラメータ:** 
  - `password` (str): ハッシュ化するパスワード。
- **戻り値:** str (ハッシュ化されたパスワード)
- **処理詳細:**
  1. 入力されたパスワードが空でないことを確認します。空の場合は `ValueError` をスローします。
  2. `bcrypt.hashpw` メソッドを使用して、パスワードをハッシュ化します。ソルトラウンド数として `salt_rounds` を使用します。
  3. ハッシュ化されたパスワードを返します。
- **エラー処理:**
  - パスワードが空の場合、`ValueError` をスローします。
  - ハッシュ化プロセス中にエラーが発生した場合、`bcrypt.exceptions.BcryptError` をキャッチし、エラーメッセージをログに記録します。

---

### `verify_password`
- **メソッド定義タイプ:** `def`
- **目的:** 入力されたパスワードがハッシュ値と一致するかを検証します。
- **パラメータ:** 
  - `password` (str): 検証するパスワード。
  - `hashed_password` (str): データベースに保存されているハッシュ値。
- **戻り値:** bool (一致する場合は `True`、一致しない場合は `False`)
- **処理詳細:**
  1. 入力されたパスワードとハッシュ値が空でないことを確認します。空の場合は `ValueError` をスローします。
  2. `bcrypt.checkpw` メソッドを使用して、パスワードとハッシュ値を比較します。
  3. 一致する場合は `True` を返し、一致しない場合は `False` を返します。
- **エラー処理:**
  - パスワードまたはハッシュ値が空の場合、`ValueError` をスローします。
  - 検証プロセス中にエラーが発生した場合、`bcrypt.exceptions.BcryptError` をキャッチし、エラーメッセージをログに記録します。

## 概要

## 概要
`ImageUploader` クラスは、料理画像のアップロード、更新、削除を管理するためのユーティリティクラスです。このクラスは、画像ファイルのバリデーション、保存先の決定、ファイルシステムまたはクラウドストレージへの保存を行います。また、画像の削除や更新時には、既存の画像ファイルの削除も行います。料理情報の視覚的な表現を提供するために重要な役割を担います。

このクラスは、メニュー管理機能の一部として動作し、料理情報の作成や更新時に呼び出されます。画像の保存先は環境変数で指定され、最大サイズや許容されるファイル形式などのバリデーションを行います。

## 使用ライブラリ
- `os`: ファイルパスの操作に使用。
- `uuid`: 一意のファイル名を生成するために使用。
- `mimetypes`: ファイル形式の検証に使用。
- `logging`: ログ記録に使用。

| `max_file_size`      | int             | 許容される最大ファイルサイズ（バイト単位）。環境変数から取得されます。 |

## フィールド詳細

### `upload_dir`
- **型:** str
- **説明:** 画像ファイルの保存先ディレクトリ。環境変数 `UPLOAD_DIR` から取得されます。ディレクトリが存在しない場合は自動的に作成されます。

### `max_file_size`
- **型:** int
- **説明:** 許容される最大ファイルサイズ（バイト単位）。環境変数 `MAX_FILE_SIZE` から取得されます。デフォルト値は 5MB（5242880 バイト）です。

### `allowed_formats`
- **型:** list[str]
- **説明:** 許容される画像形式。環境変数 `ALLOWED_FORMATS` から取得されます。デフォルト値は `['image/jpeg', 'image/png']` です。

### `logger`
- **型:** logging.Logger
- **説明:** ログ記録用のロガーオブジェクト。画像のアップロード、更新、削除時の操作履歴やエラーを記録します。

## メソッド詳細

### `__init__`
- **メソッド定義タイプ:** `def`
- **目的:** クラスの初期化を行い、設定をロードします。
- **パラメータ:** なし
- **戻り値:** なし
- **処理詳細:**
  1. 環境変数 `UPLOAD_DIR` から画像保存先ディレクトリを取得し、`upload_dir` フィールドに設定します。
  2. 環境変数 `MAX_FILE_SIZE` から最大ファイルサイズを取得し、`max_file_size` フィールドに設定します。デフォルト値は 5MB です。
  3. 環境変数 `ALLOWED_FORMATS` から許容される画像形式を取得し、`allowed_formats` フィールドに設定します。デフォルト値は `['image/jpeg', 'image/png']` です。
  4. ロガーオブジェクトを初期化し、`logger` フィールドに設定します。
  5. `upload_dir` が存在しない場合はディレクトリを作成します。
  6. 初期化が完了したことをログに記録します。

---

### `upload_image`
- **メソッド定義タイプ:** `def`
- **目的:** 画像ファイルをアップロードし、保存先のパスを返します。
- **パラメータ:**
  - `file` (bytes): アップロード対象の画像ファイル。
  - `filename` (str): 元のファイル名。
- **戻り値:** str (保存先のファイルパス)
- **処理詳細:**
  1. `validate_image` メソッドを呼び出して、ファイル形式とサイズを検証します。
  2. ファイル名を一意にするために `uuid.uuid4()` を使用して新しいファイル名を生成します。
  3. `upload_dir` を基に保存先のフルパスを構築します。
  4. ファイルを保存先に書き込みます。
  5. 保存が成功したことをログに記録します。
  6. 保存先のファイルパスを返します。
- **エラー処理:**
  - ファイル形式が無効な場合、`ValueError` をスローします。
  - ファイルサイズが許容範囲を超えている場合、`ValueError` をスローします。
  - ファイル保存中にエラーが発生した場合、`OSError` をキャッチしてログに記録し、例外を再スローします。

---

### `update_image`
- **メソッド定義タイプ:** `def`
- **目的:** 既存の画像を更新し、新しい保存先のパスを返します。
- **パラメータ:**
  - `file` (bytes): 新しい画像ファイル。
  - `filename` (str): 元のファイル名。
  - `existing_path` (str): 既存の画像ファイルのパス。
- **戻り値:** str (新しい保存先のファイルパス)
- **処理詳細:**
  1. `delete_image` メソッドを呼び出して、既存の画像ファイルを削除します。
  2. `upload_image` メソッドを呼び出して、新しい画像ファイルを保存します。
  3. 新しい保存先のファイルパスを返します。
- **エラー処理:**
  - 既存の画像ファイルの削除に失敗した場合、`OSError` をキャッチしてログに記録します。
  - 新しい画像ファイルの保存中にエラーが発生した場合、例外を再スローします。

---

### `delete_image`
- **メソッド定義タイプ:** `def`
- **目的:** 指定された画像ファイルを削除します。
- **パラメータ:**
  - `file_path` (str): 削除対象の画像ファイルのパス。
- **戻り値:** なし
- **処理詳細:**
  1. 指定されたファイルパスが存在するかを確認します。
  2. ファイルが存在する場合は削除します。
  3. 削除が成功したことをログに記録します。
- **エラー処理:**
  - ファイルが存在しない場合、警告をログに記録します。
  - ファイル削除中にエラーが発生した場合、`OSError` をキャッチしてログに記録します。

---

### `validate_image`
- **メソッド定義タイプ:** `def`
- **目的:** 画像ファイルの形式とサイズを検証します。
- **パラメータ:**
  - `file` (bytes): 検証対象の画像ファイル。
  - `filename` (str): 元のファイル名。
- **戻り値:** bool (検証結果)
- **処理詳細:**
  1. ファイルサイズを確認し、`max_file_size` を超えていないことを検証します。
  2. `mimetypes.guess_type` を使用してファイル形式を判定し、`allowed_formats` に含まれているかを確認します。
  3. 検証が成功した場合は `True` を返します。
  4. 検証が失敗した場合は `ValueError` をスローします。
- **エラー処理:**
  - ファイル形式が無効な場合、`ValueError` をスローします。
  - ファイルサイズが許容範囲を超えている場合、`ValueError` をスローします。

## 概要
`UserService` クラスは、内部ユーザーの管理を行うサービスクラスです。このクラスは、ユーザー情報の作成、取得、更新、削除、および検索機能を提供します。また、ユーザーに役割を割り当てる機能や、ユーザー情報の検証を行います。`UserService` は、`UserRepository` クラスを利用してデータベースとのやり取りを行い、`RoleRepository` クラスを使用して役割情報を管理します。

このクラスは、APIエンドポイントから呼び出され、ユーザー管理に関するビジネスロジックを実行します。認証済みの内部ユーザー（Admin権限を持つユーザー）のみがこのクラスの機能を利用できます。

## 使用ライブラリ
- `logging`: ログ記録に使用。
- `uuid`: 一意の識別子を生成するために使用。

## メソッド詳細

### `create_user`
- **メソッド定義タイプ:** `def`
- **目的:** 新しいユーザーを作成します。
- **パラメータ:** 
  - `name` (str): ユーザーの氏名。
  - `email` (str): ユーザーのメールアドレス。
  - `password` (str): ユーザーのパスワード。
  - `roles` (list[str]): ユーザーに割り当てる役割のリスト。
- **戻り値:** dict (作成されたユーザーの情報)
- **処理詳細:**
  1. `validate_user_data` メソッドを呼び出して入力データを検証します。
  2. `role_repository.get_role` メソッドを呼び出して、指定された役割が存在するかを確認します。
  3. `uuid.uuid4()` を使用して一意のユーザーIDを生成します。
  4. `user_repository.create_user` メソッドを呼び出して、データベースに新しいユーザーを挿入します。
  5. 作成されたユーザー情報を返します。
- **エラー処理:**
  - 入力データが無効な場合、`ValueError` をスローします。
  - 指定された役割が存在しない場合、`NotFoundError` をスローします。
  - データベース操作中にエラーが発生した場合、`DatabaseError` をキャッチしてログに記録します。

  2. 取得したユーザー情報を返します。
- **エラー処理:**

  3. 削除が成功したことをログに記録します。
- **エラー処理:**
  - ユーザーが存在しない場合、`NotFoundError` をスローします。
  - データベース操作中にエラーが発生した場合、`DatabaseError` をキャッチしてログに記録します。

### `validate_user_data`
- **メソッド定義タイプ:** `def`
- **目的:** ユーザー情報の入力データを検証します。
- **パラメータ:** 
  - `name` (str): ユーザーの氏名。
  - `email` (str): ユーザーのメールアドレス。
  - `password` (str): ユーザーのパスワード。
  - `roles` (list[str]): ユーザーに割り当てる役割のリスト。
- **戻り値:** bool (検証結果)
- **処理詳細:**
  1. 各フィールドが空でないことを確認します。
  2. メールアドレスの形式を正規表現で検証します。
  3. パスワードポリシーに従ってパスワードを検証します。
  4. 役割が有効な値であることを確認します。
  5. 検証が成功した場合は `True` を返します。
- **エラー処理:**
  - 検証が失敗した場合、`ValueError` をスローします。

  - `menu_item_ids` (list[int]): 更新対象の料理IDのリスト。  
  - `state` (str): 更新後の提供状況（`available`、`limited`、`sold_out` のいずれか）。  
  - `user_id` (str): 操作を実行したユーザーの一意の識別子。  
- **戻り値:** dict (更新結果を含む辞書)  
  - `updated_ids` (list[int]): 更新が成功した料理IDのリスト。  
  - `state` (str): 更新後の提供状況。  
- **処理詳細:**  
  1. **入力データのバリデーション:**  
     - `menu_item_ids` が空でないことを確認します。  
     - `state` が有効な値（`available`、`limited`、`sold_out`）であることを確認します。  
     - 無効な場合は `ValueError` をスローします。  
  2. **データベース操作:**  
     - `menu_item_repository.bulk_update_status(menu_item_ids, state)` を呼び出して、指定された料理IDリストの提供状況を一括で更新します。  
     - 更新が成功した料理IDのリストを受け取ります。  
  3. **操作履歴の記録:**  
     - `log_service.record_log(user_id, "bulk_update_menu_state", resource_id=menu_item_ids, action=f"Updated state to {state}")` を呼び出して、操作履歴を記録します。  
  4. **レスポンスの準備:**  
     - 更新が成功した料理IDのリストと新しい提供状況を含む辞書を作成し、返します。  
- **クロスクラスの関係:**  
  - `MenuItemRepository.bulk_update_status(menu_item_ids, state)`  
    - **パラメータ:** `menu_item_ids`（更新対象の料理IDリスト）、`state`（新しい提供状況）  
    - **戻り値:** 更新が成功した料理IDのリスト。  
  - `LogService.record_log(user_id, action, resource_id, ip_address)`  
    - **パラメータ:** `user_id`（操作を実行したユーザーID）、`action`（実行されたアクション）、`resource_id`（関連するリソースIDのリスト）、`ip_address`（オプション）。  
    - **戻り値:** なし。  
- **エラー処理:**  
  - `ValueError`: 入力データが無効な場合にスローします。  
  - `DatabaseError`: データベース操作中にエラーが発生した場合にスローします。  
  - `LogServiceError`: 操作履歴の記録中にエラーが発生した場合にスローします。

# クラス詳細設計ドキュメント

## クラス名
ImageHandler

## アプリケーション名
API Backend

## 概要
`ImageHandler` クラスは、料理画像のアップロード、更新、削除を管理するためのユーティリティクラスです。このクラスは、画像ファイルのバリデーション、保存先の決定、ファイルシステムまたはクラウドストレージへの保存を行います。また、画像の削除や更新時には、既存の画像ファイルの削除も行います。料理情報の視覚的な表現を提供するために重要な役割を担います。

このクラスは、メニュー管理機能の一部として動作し、料理情報の作成や更新時に呼び出されます。画像の保存先は環境変数で指定され、最大サイズや許容されるファイル形式などのバリデーションを行います。

## 使用ライブラリ
- `os`: ファイルパスの操作に使用。
- `uuid`: 一意のファイル名を生成するために使用。
- `mimetypes`: ファイル形式の検証に使用。
- `logging`: ログ記録に使用。

## フィールド詳細

### `upload_dir`
- **型:** str
- **説明:** 画像ファイルの保存先ディレクトリ。環境変数 `UPLOAD_DIR` から取得されます。ディレクトリが存在しない場合は自動的に作成されます。

### `max_file_size`
- **型:** int
- **説明:** 許容される最大ファイルサイズ（バイト単位）。環境変数 `MAX_FILE_SIZE` から取得されます。デフォルト値は 5MB（5242880 バイト）です。

### `allowed_formats`
- **型:** list[str]
- **説明:** 許容される画像形式。環境変数 `ALLOWED_FORMATS` から取得されます。デフォルト値は `['image/jpeg', 'image/png']` です。

### `logger`
- **型:** logging.Logger
- **説明:** ログ記録用のロガーオブジェクト。画像のアップロード、更新、削除時の操作履歴やエラーを記録します。

---

## メソッド詳細

### `__init__`
- **メソッド定義タイプ:** `def`
- **目的:** クラスの初期化を行い、設定をロードします。
- **パラメータ:** なし
- **戻り値:** なし
- **処理詳細:**
  1. 環境変数 `UPLOAD_DIR` から画像保存先ディレクトリを取得し、`upload_dir` フィールドに設定します。
  2. 環境変数 `MAX_FILE_SIZE` から最大ファイルサイズを取得し、`max_file_size` フィールドに設定します。デフォルト値は 5MB です。
  3. 環境変数 `ALLOWED_FORMATS` から許容される画像形式を取得し、`allowed_formats` フィールドに設定します。デフォルト値は `['image/jpeg', 'image/png']` です。
  4. ロガーオブジェクトを初期化し、`logger` フィールドに設定します。
  5. `upload_dir` が存在しない場合はディレクトリを作成します。
  6. 初期化が完了したことをログに記録します。

---

### `upload_image`
- **メソッド定義タイプ:** `def`
- **目的:** 画像ファイルをアップロードし、保存先のパスを返します。
- **パラメータ:**
  - `file` (bytes): アップロード対象の画像ファイル。
  - `filename` (str): 元のファイル名。
- **戻り値:** str (保存先のファイルパス)
- **処理詳細:**
  1. `validate_image` メソッドを呼び出して、ファイル形式とサイズを検証します。
  2. ファイル名を一意にするために `uuid.uuid4()` を使用して新しいファイル名を生成します。
  3. `upload_dir` を基に保存先のフルパスを構築します。
  4. ファイルを保存先に書き込みます。
  5. 保存が成功したことをログに記録します。
  6. 保存先のファイルパスを返します。
- **エラー処理:**
  - ファイル形式が無効な場合、`ValueError` をスローします。
  - ファイルサイズが許容範囲を超えている場合、`ValueError` をスローします。
  - ファイル保存中にエラーが発生した場合、`OSError` をキャッチしてログに記録し、例外を再スローします。

---

### `update_image`
- **メソッド定義タイプ:** `def`
- **目的:** 既存の画像を更新し、新しい保存先のパスを返します。
- **パラメータ:**
  - `file` (bytes): 新しい画像ファイル。
  - `filename` (str): 元のファイル名。
  - `existing_path` (str): 既存の画像ファイルのパス。
- **戻り値:** str (新しい保存先のファイルパス)
- **処理詳細:**
  1. `delete_image` メソッドを呼び出して、既存の画像ファイルを削除します。
  2. `upload_image` メソッドを呼び出して、新しい画像ファイルを保存します。
  3. 新しい保存先のファイルパスを返します。
- **エラー処理:**
  - 既存の画像ファイルの削除に失敗した場合、`OSError` をキャッチしてログに記録します。
  - 新しい画像ファイルの保存中にエラーが発生した場合、例外を再スローします。

---

### `delete_image`
- **メソッド定義タイプ:** `def`
- **目的:** 指定された画像ファイルを削除します。
- **パラメータ:**
  - `file_path` (str): 削除対象の画像ファイルのパス。
- **戻り値:** なし
- **処理詳細:**
  1. 指定されたファイルパスが存在するかを確認します。
  2. ファイルが存在する場合は削除します。
  3. 削除が成功したことをログに記録します。
- **エラー処理:**
  - ファイルが存在しない場合、警告をログに記録します。
  - ファイル削除中にエラーが発生した場合、`OSError` をキャッチしてログに記録します。

---

### `validate_image`
- **メソッド定義タイプ:** `def`
- **目的:** 画像ファイルの形式とサイズを検証します。
- **パラメータ:**
  - `file` (bytes): 検証対象の画像ファイル。
  - `filename` (str): 元のファイル名。
- **戻り値:** bool (検証結果)
- **処理詳細:**
  1. ファイルサイズを確認し、`max_file_size` を超えていないことを検証します。
  2. `mimetypes.guess_type` を使用してファイル形式を判定し、`allowed_formats` に含まれているかを確認します。
  3. 検証が成功した場合は `True` を返します。
  4. 検証が失敗した場合は `ValueError` をスローします。
- **エラー処理:**
  - ファイル形式が無効な場合、`ValueError` をスローします。
  - ファイルサイズが許容範囲を超えている場合、`ValueError` をスローします。
